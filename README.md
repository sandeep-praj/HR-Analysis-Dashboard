# 📊 HR Analytics Dashboard

## 📌 Project Overview

The **HR Analytics Dashboard** is a data analytics project created to analyze employee data and understand important HR-related insights such as **employee attrition, salary, job satisfaction, employee demographics, departments, and experience**.

The project uses **Excel for data cleaning and analysis** and **Excel for interactive data visualization and dashboard creation**.

The main goal of this project is to help HR teams understand employee trends and identify factors related to employee attrition.

## 🛠️ Tools & Technologies

* **Power Query**

## 📂 Dataset

The dataset contains employee information and HR-related attributes.
